# ワークフロー一覧

本ディレクトリは、プロジェクト各工程の「進め方」「停止条件」「ドキュメントの扱い」を定めるナレッジベースおよび開発プロセスの記録場所です。

## ワークフロー・原則ドキュメント

- **`information-architecture.md`**
  - プロジェクト全体を通底する「情報設計（Information Architecture）」の恒久原則。全構造変更の基準。
- **`document-governance.md`**
  - 文書の配置、ライフサイクル、退役の基準。
- **`planning-workflow.md`**
  - 企画フェーズの進め方と停止条件。
- **`design-workflow.md`**
  - 設計フェーズの進め方と停止条件。
- **`specification-workflow.md`**
  - 仕様策定フェーズの進め方と停止条件。
- **`implementation-workflow.md`**
  - 実装・成果物検証フェーズの進め方と停止条件。
- **`rule-addition-criteria.md`**
  - プロジェクトルール（AGENTS.md等）の追加・修正を行う際の判断基準。
