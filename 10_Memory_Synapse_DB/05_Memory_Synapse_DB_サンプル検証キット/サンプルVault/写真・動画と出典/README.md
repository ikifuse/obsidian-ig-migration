# 写真・動画と出典

このフォルダーの写真と動画は、Memory Synapse DBのブラウザー確認用モックとサンプルVaultで共用する。正式Obsidianプラグイン、実Vault、IGP・IGR・IGSでは使用しない。

写真は投稿のハッシュタグと対応する検証用素材として選び、2026年7月30日に被写体を目視確認した。Openverseは検索とライセンス情報の確認に使用し、元素材ページも各行に記録する。

機械検査用の出典台帳は`sources.json`にあり、各素材のVault相対パス、元ページ、作者、ライセンスおよびライセンス参照先を保持する。表示時に外部ネットワークから素材を取得しない。
