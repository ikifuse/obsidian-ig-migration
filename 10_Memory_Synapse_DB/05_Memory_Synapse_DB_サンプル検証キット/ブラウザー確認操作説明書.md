# Memory Synapse DB ブラウザー確認操作説明書

## この説明書の目的

この説明書は、Memory Synapse DBの画面を初めて見る人が、**どこを押すか、何が起これば正しいか、何を報告すればよいか**を順番に確認するためのものです。

GitHubやプログラムの知識は必要ありません。確認する人が行うのは、ブラウザーでボタンを押し、表示された結果を見ることです。

> [!IMPORTANT]
> このブラウザー画面は、架空データを使った確認用見本です。実際のObsidianや日常利用Vaultは変更しません。ブラウザーを再読み込みすると、操作結果は初期状態へ戻ります。

## 最初に行うこと

1. [ブラウザー確認用モックを開く](ブラウザー確認用モック/index.html)。
2. 画面上部に、確認用の見本であり実Vaultへ保存しない旨が表示されることを確認する。
3. 以後、一つの確認項目を始める前に、画面上部の`初期状態へ戻す`を押す。
4. 問題を見つけた場合は、そこで止めて、画面のスクリーンショットを撮る。

確認結果は、次の三つだけ伝えれば十分です。

- 確認番号（例：`B-08`）
- 期待した結果
- 実際に表示された結果とスクリーンショット

## 画面の見方

| 場所 | 役割 |
|---|---|
| 左側 | 投稿、人物、場所、タグ、検査記録のファイルを選ぶ |
| 中央 | 選んだ投稿・カード・一覧・検証ケースを表示する |
| 右側 | 選択中の個別カードや融合状態を詳しく見る |

狭い画面では、中央上部の`エクスプローラー`で左側、`Memory Synapse`で右側を開きます。`×`、暗い背景、または`Esc`で中央へ戻ります。

## 基本操作を順番に確認する

### 1. 投稿を開く

1. `初期状態へ戻す`を押す。
2. 左側の`Posts`、`Reels`、`Stories`のいずれかを開く。
3. 投稿ファイルを一つ押す。

合格条件：

- 中央に投稿本文、日時、写真または動画、関連するMention・Location・Tagが表示される。
- 関連カードを押すと、そのカードの表示へ移動する。

### 2. カードを検索する

1. `リンク一覧`を押す。
2. 検索欄へ`son_goku`と入力する。
3. `手書きあり`を押す。
4. `絞り込み解除`を押す。

合格条件：

- `@son_goku`を見つけられる。
- `手書きあり`で対象が絞られる。
- `絞り込み解除`で全体表示へ戻る。

### 3. 二枚を融合する

1. `初期状態へ戻す`を押す。
2. `リンク一覧`を押す。
3. 融合していないカードを一枚選び、`融合へ追加`を押す。カードを別カードへドラッグしてもよい。
4. 融合相手を選ぶ。
5. 関係管理カードと、存在する種類ごとの代表を確認する。
6. `融合する`を押す。

合格条件：

- 確認前に、どのカードが関係を管理し、どのカードが種類別代表になるか分かる。
- 実行後も個別カードは消えず、融合単位の受け皿内で確認できる。
- 種類の異なるカードを融合した場合、種類ごとの代表が大きなカードへ表示される。

### 4. 手書き情報を入れる

1. `初期状態へ戻す`を押す。
2. `@son_goku`などの個別カードを開く。
3. `手書き`を押す。
4. 表示名または自由メモを変更する。
5. `保存内容を確認`を押し、変更前後を見る。
6. `保存`を押す。
7. `元情報を見る`も押す。

合格条件：

- Mention、Location、Tagで必要な入力欄だけが表示される。
- 入力した空でない項目だけが表示で優先される。
- 元情報は消えず、引き続き確認できる。
- ブラウザーを再読み込みすると変更が消え、初期状態へ戻る。

### 5. 分離・解体・元に戻す

1. `初期状態へ戻す`を押す。
2. 初期状態にある`@sazae_fuguta`、`大阪城`、`#野球バット`の融合単位を開く。
3. 受け皿内の一枚で`このカードを分離`を押す。
4. `元に戻す`を押す。
5. `融合をすべて解体`を押す。

合格条件：

- 分離では選んだ一枚だけが単独へ戻る。
- `元に戻す`で、関係管理カードと種類別代表を含む直前の状態へ戻る。
- 解体では全カードが単独へ戻るが、個別カードの元情報と手書き情報は消えない。

## 途中で止める条件

次のどれかが起きたら、その先の確認は行わずに報告してください。

- 説明書にあるボタンが見つからない。
- ボタン名や結果が説明書と異なる。
- 何を選べばよいか判断できないまま確定を求められる。
- 元情報や個別カードが消えたように見える。
- ブラウザーの再読み込み後も変更が残る。
- 実在する個人情報や、利用者のパソコン固有のパスが見える。
- ブラウザー以外のファイルを変更したという表示が出る。
