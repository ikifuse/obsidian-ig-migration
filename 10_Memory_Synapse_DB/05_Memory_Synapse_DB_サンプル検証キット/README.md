# Memory Synapse DB サンプル検証キット

## この05は何か

このフォルダー全体が、Memory Synapse DBを公開環境で段階的に確かめるための**独立サンプル検証キット**です。正式なObsidianプラグインではなく、`04_Memory_Synapse_DB_実行コード/`の通常ビルドから生成される成果物でもありません。

表示されるカード、投稿、人物の活動、位置情報、関連付けおよび検査結果は、動作確認のための架空データです。実在する作品名や一般名称を表示確認に使用していても、実際の利用者のInstagram履歴を示しません。

## 中にある5つのもの

| 内容 | 場所 | 役割 |
|---|---|---|
| ブラウザー確認用モック | [モックを開く](ブラウザー確認用モック/index.html) | インストールせずに画面、配置、操作を確認する |
| サンプルデータ | [サンプルデータの案内](サンプルデータ/README.md) | 90投稿、90 Synapse、3 SystemLogsの公開用JSON正本 |
| サンプルVault | [サンプルVaultの案内](サンプルVault/README.md) | Obsidianで開いてMarkdown、Wikiリンク、写真・動画を確認する |
| 検証ケース台帳 | [検証ケース台帳の案内](検証ケース台帳/README.md) | P-01〜P-30、R-01〜R-30、S-01〜S-30の条件と期待結果を対応付ける |
| 写真・動画と出典 | [写真・動画と出典の案内](サンプルVault/写真・動画と出典/README.md) | モックとサンプルVaultが共用するローカル素材と出典・ライセンス記録 |

写真・動画をサンプルVault内に置いているのは、Obsidianが同じファイルをそのまま表示でき、モック用とVault用に二重管理しないためです。

## 確認方法

初めて確認する場合は、先に[ブラウザー確認操作説明書](ブラウザー確認操作説明書.md)を開いてください。どこを押すか、何が起これば正しいか、問題があったとき何を伝えるかを、確認番号ごとに説明しています。

### 1. ブラウザーだけで確認する

[▶ ブラウザー確認用モックを開く](ブラウザー確認用モック/index.html)

画面内の操作はブラウザー上の一時状態だけを変更し、再読み込みすると初期状態へ戻ります。

デスクトップ幅では左右サイドバーとの境界をドラッグして、24インチ全画面だけでなく左右分割した幅でも確認できます。境界にキーボードフォーカスを移した場合は、左右矢印キーでも幅を変更できます。狭い幅では画面上部の`エクスプローラー`と`Memory Synapse`から左右領域を一時表示し、`×`、背景または`Esc`で中央表示へ戻ります。

右側の選択中カード詳細は、カテゴリ固有のJSONを一塊で表示せず、Mentionでは元のメンション・名前・電話・Web・自由メモ、Tagでは元のタグ・自由メモ、Locationでは場所名・座標・住所・活動ID・元ファイル・人間の記憶を項目別に表示します。

手書きは単独カードまたは受け皿内の個別カードから行います。Tag、Mention、Locationごとに必要な入力欄だけを表示し、保存した非空項目だけを優先します。空項目は同じ個別カードの移行時点情報へ戻り、元情報は`元情報を見る`から確認できます。融合単位の大きなカードは、カテゴリ別代表から毎回組み立てる読み取り専用表示です。

## 画面とボタンの使い方

### 常に見える場所

| 場所 | ボタン・操作 | できること |
|---|---|---|
| 左サイドバー | `▶` / `▼`のフォルダー | Posts、Reels、Stories、Synapses、SystemLogsを開閉する |
| 左サイドバー | 投稿ファイル | 対応する投稿と検証番号を中央で開く |
| 左サイドバー | Synapseファイル | Mention、Location、Tagの個別カードを中央と右側で開く |
| 左サイドバー | SystemLogファイル | 検査ログを中央で開く |
| 中央上部 | `リンク一覧` | 検索・絞り込みとカード一覧へ戻る |
| 中央上部 | `検証ケース` | P-01〜S-30の90検証ケース一覧を開く |
| 中央上部 | `初期状態へ戻す` | 融合、分離、手書き等のブラウザー内変更を全て初期化する |
| 中央上部 | `元に戻す` | 直前の融合、分離、手書き等の操作を一回取り消す |
| 右上部 | `検証ケース` / `リンク一覧` | 中央上部と同じ画面へ移動する |
| 左右の境界線 | ドラッグ、またはフォーカスして矢印キー | デスクトップ幅で左右サイドバーの幅を変える |
| 狭い画面の中央上部 | `エクスプローラー` / `Memory Synapse` | 一時的に左または右サイドバーを開く |
| 狭い画面のサイドバー | `×`、暗い背景、`Esc` | サイドバーを閉じて中央へ戻る |

### リンク一覧

| 場所 | ボタン・操作 | できること |
|---|---|---|
| 検索欄 | 文字入力 | カード名、別名、元情報、関連投稿から探す |
| 種類 | `Tag` / `Mention` / `Location` | 該当種類を絞り込む。複数選択できる |
| 状態 | `単独` / `関係管理カード` / `融合済み` | カードの所属状態で絞り込む |
| 状態 | `手書きあり` | 手書き情報を持つカードだけにする |
| 絞り込み欄 | `絞り込み解除` | 検索条件と絞り込みを全て解除する |
| カード | クリック | 単独カードまたは融合単位の詳細を開く |
| カード | 別カードへドラッグ | 融合候補と関係管理カード・カテゴリ別代表の確認画面を開く |

### 融合単位の大きなカード

| 場所 | ボタン | できること |
|---|---|---|
| 各カテゴリ表示 | `他のカードを見る` | 下の受け皿にある同カテゴリの個別カードへ移動する |
| 大きなカード下部 | `関係管理カードを変更` | 融合関係を管理する既存カードだけを変更する |
| 大きなカード下部 | `代表を変更` | Mention、Location、Tagの表示代表だけを変更する |
| 大きなカード下部 | `融合をすべて解体` | 全カードを単独へ戻す。元情報と手書き情報は消さない |

大きなカードは読み取り専用なので、ここには`手書き`ボタンを置きません。

### 単独カード・受け皿内の個別カード

| 場所 | ボタン | できること |
|---|---|---|
| 個別カード | `元情報を見る` | 手書きで置き換えていない移行時点情報を確認する |
| 手書き済み個別カード | `保存済み手書き情報` | その個別カードに保存されている手書き項目を確認する |
| 個別カード | 関連投稿リンク | 対応する投稿を中央で開く |
| 個別カード | `手書き` | カード種類に必要な項目だけを編集する |
| 単独カード | `融合へ追加` | 融合相手と関係管理カード・代表を確認する画面へ進む |
| 受け皿内カード | `このカードを分離` | 選択した一枚だけを融合単位から外す |
| 受け皿内カード | `右側で確認` | その個別カードの現在地、実効値、元情報、手書き、関連投稿を右側へ表示する |

### 確認画面・手書き画面

| ボタン | できること |
|---|---|
| `保存内容を確認` | 保存前に現在値、操作後、変更対象、非変更情報を確認する |
| `保存` | ブラウザー内の対象個別カードへ手書き情報を反映する |
| `融合する` | 選択した関係管理カードとカテゴリ別代表で融合する |
| `変更内容を確認して反映` | 関係管理カードまたは代表の選択結果を反映する |
| `キャンセル` | 状態を変更せず確認画面を閉じる |

### 2. サンプルVaultだけを確認する

Obsidianの「保管庫としてフォルダーを開く」で[サンプルVault](サンプルVault/)を選びます。投稿Markdown、Synapse、SystemLogs、Wikiリンク、写真・動画および意図的な欠損ケースを標準表示で確認できます。

### 3. 読み取り専用仮プラグインを確認する

日常利用Vaultではなく、この[サンプルVault](サンプルVault/)の複製を使います。[06_Memory_Synapse_DB_仮プラグイン](../06_Memory_Synapse_DB_仮プラグイン/memory-synapse-db/)を複製側の`.obsidian/plugins/memory-synapse-db/`へ配置し、Obsidianで有効化します。確認後は無効化し、そのプラグインフォルダーを削除します。

05には`.obsidian/plugins/`を同梱しません。06の導入、無効化、削除は利用者が隔離した複製側だけで行います。

## データ境界

- 実Vault、`output_IGP`、`output_IGR`、`output_IGS`、`output_IGC`を読み書きしません。
- APIキー、利用者固有設定、個人情報、利用者環境の絶対パスを含めません。
- 表示時に外部ネットワークから写真・動画を取得しません。
- サンプルデータ、検証番号、サンプルメディア、モックのObsidian風外枠を04・06・08へ直接移植しません。
- 05の変更を採用するときは、設計・仕様の承認を経てから実装へ渡します。

## 構成検査

リポジトリ直下で次を実行します。

```bash
node 10_Memory_Synapse_DB/05_Memory_Synapse_DB_サンプル検証キット/tools/validate-sample-kit.mjs
node 10_Memory_Synapse_DB/05_Memory_Synapse_DB_サンプル検証キット/tools/validate-ui-contract.mjs
```

一つ目の検査は、件数、ケース番号、Vault内パス、関連カード、`schema_version: 2`相当の関係管理カードとカテゴリ別代表、ローカルメディア、出典台帳、05専用ファイルおよび禁止物の混入を確認します。二つ目は、B-07の読み取り専用集約、B-08の種類別手書きと項目単位の優先表示、B-31の可変境界、B-32の狭幅パネルに必要なUI契約と幅計算を確認します。
