# 04_画面の役割

## 担当すること

- Obsidian内で融合グループ、カテゴリ別代表、個別カード、関連投稿および問題状態を表示する
- 関係管理カードとカテゴリ別代表を区別して表示する
- 大きな集約表示は読み取り専用とし、個別カードが持つ手書き情報を項目単位で優先表示する
- 融合、分離、関係管理・代表変更、個別カードの手書き、取消および初期化を画面セッション内だけで試す
- 操作結果とエラー理由を利用者へ表示する
- カードと関連投稿をObsidian標準タブで開く

## 担当しないこと

- 融合・分離規則の独自判断
- カード構造の独自定義
- 投稿の写真、動画、本文、タグ、メンション、位置情報および末尾リンクの独自再構成
- Obsidian標準エクスプローラー、標準タブまたはブラウザー確認用外枠の再実装
- 外部ネットワーク通信
