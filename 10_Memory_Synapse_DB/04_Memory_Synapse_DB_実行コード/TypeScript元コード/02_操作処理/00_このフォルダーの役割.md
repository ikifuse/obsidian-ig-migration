# 02_操作処理の役割

## 担当すること

- 融合候補の展開、関係管理カードとカテゴリ別代表の推奨
- 融合グループ同士を入れ子にせず一列に統合
- 関係管理カードとカテゴリ別代表の個別変更、構成カードの分離、融合全体の解体
- 個別カードへの手書き情報の保存と、項目単位の手書き優先表示
- 多重所属などの状態検証
- 画面セッション中の直前操作の取消

## 担当しないこと

- HTMLやObsidian画面の表示
- Markdownファイルの直接書き換え
- 外部通信

## 含まれるコード

`融合.ts`、`分離.ts`、`関係管理・代表変更.ts`、`手書き保存.ts`、`実効表示.ts`、`状態参照.ts`、`状態検証.ts`、`元に戻す.ts`に責任を分ける。

`操作処理.test.ts`は、推奨、平坦な融合、カテゴリ別代表、分離、項目単位の手書き優先および多重所属検出を自動確認する。
