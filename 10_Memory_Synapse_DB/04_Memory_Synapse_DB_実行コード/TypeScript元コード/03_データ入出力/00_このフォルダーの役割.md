# 03_データ入出力の役割

## 担当すること

- 対象ルート内のTag、Mention、Locationカードを読み取る
- MarkdownからWikiリンクを読み取る
- Wikiリンク文字列をパスと表示名へ分ける
- 関連投稿と融合状態、手書き情報、問題状態を読み取る
- schema version 2を読み、旧schema version 1は画面セッション内だけで変換する
- Vault読取結果を画面へ渡せる形にそろえる

## 担当しないこと

- 融合するかどうかの判断
- 画面表示
- 現段階でのVault書き込み

## 現在の境界

`Obsidian_Vaultデータ.ts`は`cachedRead`による読取だけを行う。Markdownの作成、変更、移動、削除はまだ実装しない。

`トランザクション生成.ts`とMarkdown更新関数は、schema version 2の将来の08実装を人間が監査できるよう分離して置くが、06の入口からは参照しない。

06ではMarkdown更新と操作履歴保存を実行しない。書き込み処理は、08の対象、復旧試験および停止点が別に承認された後だけ入口へ接続する。
