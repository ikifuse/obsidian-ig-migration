- オーナーが手動で更新する必要はありません。
- 一つの変更案件につき一行を使い、同じ変更サイクルではその行を更新します。

- コードを戻す基準点はGitコミットです。この台帳だけでコードを復元しません。

## 更新するタイミング

AIは次の場合だけ、対象行と先頭プロパティを更新します。

1. 新しい変更サイクルを開始したとき
2. 05完成候補と仕様差分を提示したとき
3. 設計承認が別に必要になったとき
4. 仕様が承認され、04実装へ進むとき
5. 04の自動検査が合格または不合格になったとき
6. 06を生成して実物確認を待つとき
7. 06が承認され、変更サイクルを完了したとき
8. 範囲外変更、未確認事項または不合格により停止したとき

05探索中の細かな途中状態は、許可された専用ブランチの`WIP（未承認）`コミットで保存し、本台帳へ列挙しません。
