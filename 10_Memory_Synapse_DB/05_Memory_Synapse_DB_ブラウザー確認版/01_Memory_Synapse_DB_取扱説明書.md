# Memory Synapse DB 取扱説明書

この記事は、Memory Synapse DB（メモリー・シナプス・ディービー）プラグインでできることを、中学生でもわかるように説明するガイドです。
この「05_ブラウザー確認版」は、実際のファイル（Vault）を壊すことなく、プラグインがどんな動きをするか安全に試せる「永遠のテスト用モック（模型）」として作られています。

---

## 1. プラグインでできること（概要）

このプラグインは、Obsidianの中に散らばっている「Mention（人）」「Location（場所）」「Tag（タグ）」のカードをつなぎ合わせて、一つの「大きなカード」としてまとめるための道具です。

### 📌 できることリスト

- **カードの合体（融合）**
  同じ人や同じ場所のカードが複数ある場合、それらをドラッグ＆ドロップ（マウスでつかんで離す操作）で一つにまとめることができます。
  
- **自動おすすめ機能（レコメンド）**
  どのカードを「親（大きなカード）」にするか迷ったとき、プラグインが「Mention（人）」や「Location（場所）」を優先して「これを親にするのがおすすめですよ！」と教えてくれます。

- **手書きメモの保存**
  それぞれのカードに「本名」「住所」「電話番号」や「個人的なメモ」を書き込んで保存できます。保存したメモは、カードが合体しても消えずに残ります。

- **表示の切り替え**
  大きなカードの中身を、「もともとのカード（Source）」として見るか、「手書きメモ（Handwritten）」として見るか、ボタン一つで切り替えられます。

- **間違えたときの取り消し（Undo / 元に戻す）**
  もし間違えてカードを合体させてしまっても、上の「↩（元に戻す）」ボタンを押せば、直前の状態にサッと戻せます。

- **安全な書き込み（トランザクション）**
  ※（これは実際のプラグインのみの機能です）
  複数のファイルを同時に更新するときに、途中でエラーが起きたら「すべてなかったこと（ロールバック）」にしてファイルを壊さないように守る機能がついています。

## 2. 05_ブラウザー確認版（テストモック）の遊び方

このフォルダーに入っている `index.html` をブラウザー（ChromeやSafariなど）で開くと、すぐにテスト画面が立ち上がります。

1. **画面の左側（エクスプローラー）**
   フォルダツリーがあります。ここから「Mentions」や「Locations」のフォルダを開いて、カードをクリックしてみてください。

2. **画面の真ん中（カード一覧と詳細）**
   カードを選ぶと、そのカードの情報（どんな投稿に関連しているかなど）が表示されます。

3. **合体（融合）を試す**
   - リストにあるカードの横の「⋮⋮（ドラッグ用の持ち手）」をマウスでクリックしたまま引っ張って、別のカードの上で離してみてください。
   - 「融合しますか？」という画面が出るので、指示に従って進めるとカードが合体します。

4. **手書きメモを試す**
   - カードを選んで、上にある「📝 手書き」ボタンを押します。
   - フォームが開くので、好きな名前やメモを入れて「保存」を押します。

5. **元に戻す・リセット**
   - 失敗したら右上の「↩（元に戻す）」ボタン。
   - 最初からやり直したくなったら「🔄（リセット）」ボタンを押せば、いつでもデータが初期状態に復活します！
