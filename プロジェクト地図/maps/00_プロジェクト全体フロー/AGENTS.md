# AGENTS

## 役割

- 本ディレクトリは、親プロジェクトの発端、工程順、並列工程、現在地、親完成、独立後続を示す孫プロジェクトとする。
- 表現の主軸は、上から下へ進む縦型フローチャートとする。
- 詳細判断を一枚へ詰め込まず、対応する孫プロジェクトへの入口を示す。

## 固有の禁止事項

- 時系列、工程順、並列関係、責任境界を同じ線として混同しない。
- Memory Synapse DBを親プロジェクトの完成条件へ含めない。
- IGP・IGR・IGSの完成済み・凍結状態を、未完了工程として表さない。
- 非公開の`03_継続中の判断材料・引継ぎ`本文を参照元または素材にしない。
