# 04 仕様地図 作業ガイド

## 根拠の入口

- `../../../../04_IG移行仕様書/00_仕様書目次.md`
- 目次から選んだ対象仕様分冊
- 対応する現役設計分冊
- `../../../01_プロジェクト地図企画書v1.0.md`

## 進め方

1. 仕様目次で正本と各分冊の責任範囲を確認する。
2. 入力、処理、出力、例外、再実行、完了条件を分ける。
3. 05〜08との対応を示し、実装状況とは分離する。
4. 仕様の比較と追跡に適した地図形式を設計工程で比較する。

## 停止条件

子設計が承認されるまで、仕様本文の一括転記、地図データ作成、表示実装へ進まない。
