# 02 設計地図 作業ガイド

## 根拠の入口

- `../../../../02_IG移行設計書/00_設計書目次.md`
- 目次に記載された現役設計6冊
- `../../../01_プロジェクト地図企画書v1.0.md`

## 進め方

1. 設計目次で正本と分冊の役割を確認する。
2. 表したい関係に必要な分冊だけを選び、選定理由を記録する。
3. 企画条件、設計判断、責任境界、接続、検証の関係を分ける。
4. 六分冊の粒度を維持できる地図形式を比較する。

## 停止条件

子設計が承認されるまで、現役設計本文の一括転記、地図データ作成、表示実装へ進まない。
