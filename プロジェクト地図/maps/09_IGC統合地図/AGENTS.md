# AGENTS

## 役割

- 本ディレクトリは、IGC統合の目的、専用設計、分冊仕様、実行コード、安全更新、上流境界、親完成との関係を理解する孫プロジェクトとする。
- IGC側だけで解決する原則と、上流変更に別承認が必要な境界を明確に示す。
- 表現方法は未確定とし、設計工程で比較する。

## 固有の禁止事項

- IGCの要求を理由に、IGP・IGR・IGSへ自動的に変更を戻さない。
- IGCの企画、設計、仕様、実装、成果物検証を同じ状態として混ぜない。
- 作業中の実データ、ログ、ローカルパスを地図素材へ含めない。
