# 親AGENTS・docs判断ルーティング 作業ガイド

## 根拠の入口

- `../../../../AGENTS.md`
- `../../../../docs/00_ワークフロー一覧.md`
- 作業種類に対応する親`docs/`の現役文書
- `../../../01_プロジェクト地図企画書v1.0.md`

## 進め方

1. 作業種類、最初に読む文書、追加資料、承認、停止点を分ける。
2. 親ルールと工程別workflowの関係を確認する。
3. 地図には短い判断条件と正本への入口を置き、規則本文を複製しない。
4. 初めて見る人とAIが同じ参照先へ到達できるか検証する。

## 停止条件

子設計が承認されるまで、ルール本文の転記、ルーティングデータ作成、表示実装へ進まない。
