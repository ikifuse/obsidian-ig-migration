# AGENTS

## 役割

- 本ディレクトリは、作業内容から、読む文書、適用するルール、承認、停止点へ案内する孫プロジェクトとする。
- 表現の主軸は、条件分岐をたどる判断ルーティング図とする。
- 親`AGENTS.md`と親`docs/`の本文を置き換えず、正本へ到達する入口を示す。

## 固有の禁止事項

- 目次の階層をそのまま主工程のフローとして描かない。
- ルール本文を地図へ複製し、正本と競合させない。
- 読み込み、判断、承認、停止を同じ意味の分岐として混ぜない。
- 非公開資料の内容を表示せず、存在と非公開境界だけを示す。
