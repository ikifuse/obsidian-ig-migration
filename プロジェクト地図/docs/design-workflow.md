# 設計工程

## 開始条件

オーナーが`01_プロジェクト地図企画書v1.0.md`を確認し、設計工程への移行を承認していること。

## 設計するもの

- 七地図それぞれが答える問い
- 各地図の中心、分岐、因果関係、並列関係、境界、現在地
- 同じ情報を複数地図へ置く場合の責任分担
- 地図間の移動と、全体地図へ戻る経路
- 初期表示、展開、縮小、移動、現在位置表示
- 色、文字、余白、線、状態表示の視覚体系
- デスクトップとモバイルの判読方法
- 現行単一地図を参考資料として保存する方法

## 表現方法の比較

各地図を自動的にフローチャートまたはマインドマップと呼びません。次を比較し、表したい関係に合うものを選びます。

- フローチャート
- マインドマップ
- 概念地図
- 階層ツリー
- レイヤー図
- 状態遷移図
- 複数方式の組合せ

## 技術候補の比較

HTML/CSSが正解であることを前提にしません。少なくとも次の観点で候補を比較します。

- GitHub Pagesで安定して公開できる
- macOS、一般的なブラウザー、スマートフォンで閲覧できる
- 外部サービスや特定AIへ依存しない
- 大量の詳細分岐を展開しても判読できる
- キーボード、タップ、クリックで操作できる
- 将来の修正時に人間とAIが構造を追える
- 見た目を一貫して磨ける
- 読み込み失敗時に原因を確認できる

候補には、素のHTML/CSS/JavaScript、SVG、Canvas、適切な可視化ライブラリ、静的生成を含めます。実物の小規模試作で比較し、名称や流行だけで決定しません。

## 完了と停止

七地図の構造、表現方法、視覚体系、技術構成、既存地図の保存方法、検証方法を設計書へまとめ、オーナーが確認したところで停止します。承認前に本実装へ進みません。
