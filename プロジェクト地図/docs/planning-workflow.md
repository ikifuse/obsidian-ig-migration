# 企画工程

## この工程で決めること

- なぜ地図が必要か
- 誰が、どの状況で使うか
- 七地図へ分ける理由と各地図の役割
- 地図によって実現したい価値
- 対象範囲と対象外
- 完成と判定する条件

## この工程で決めないこと

- HTML/CSS、SVG、Canvas、外部ライブラリなどの技術
- フローチャート、マインドマップ、概念地図などの具体的表現
- ノード配置、色、寸法、線、アニメーション
- ファイル分割、JavaScript構造、データ形式

これらは、企画承認後の設計工程で候補を比較して決定します。

## 確認する根拠

- 親プロジェクトの企画書と現役設計
- README、親`AGENTS.md`、親`docs`
- 現在の単一地図で分かりやすかった点と混乱した点
- オーナーが地図を必要とした理由

## 完了と停止

企画書に目的、理由、七地図、価値、対象範囲、対象外、完成条件が揃い、オーナーが内容を確認したところで停止します。設計工程へは自動的に進みません。
