# ワークフロー一覧

本ディレクトリは、プロジェクト地図子プロジェクトを、目的を見失わず完成させるための進め方と停止条件を定めます。

## 文書一覧

- [[planning-workflow|planning-workflow.md]]
  - 目的、理由、七地図の役割、対象範囲、完成条件を決める。
- [[design-workflow|design-workflow.md]]
  - 表す関係、情報階層、地図間移動、見た目、表現方法、技術候補を比較する。
- [[implementation-validation-workflow|implementation-validation-workflow.md]]
  - 承認済み設計を実装し、デスクトップ・モバイル・公開URLで検証する。

## 共通の停止線

企画、設計、実装、公開を同時に進めません。各工程の成果をオーナーが確認し、次工程への移行を承認するまで停止します。
