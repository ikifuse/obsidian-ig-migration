# Metaエクスポートを個人文脈基盤へ再構造化
### `obsidian-ig-migration` / `Memory Synapse`

> **Instagramからエクスポートした約10年分の人生ログを、原本を損なうことなく、Obsidian上で人間とAIが共に育てられる「第二の脳（知識基盤）」へと変換・統合するプロジェクトです。**

---

## 🌟 本プロジェクトが提供する2大コア機能

本リポジトリは、**「① Instagram完全移行パイプライン（CLI）」** と **「② Memory Synapse DB（Obsidian専用プラグイン）」** の2つの連動システムで構成されています。

```text
[Instagram エクスポート原本 (JSON/メディア)]
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ ① IG移行パイプライン (Python)                           │
│   ├── IGP（通常投稿） ──> output_IGP (1,842件)         │
│   ├── IGR（リール）   ──> output_IGR (77件)            │
│   └── IGS（ストーリー）──> output_IGS (1,521件)         │
│                         │                              │
│   ▼ 完全一致名寄せ・統合                                │
│   IGC（統合工程）     ──> output_IGC (5,131 Synapses) │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ ② Memory Synapse DB (Obsidian Custom Plugin / GUI)    │
│   ├── カード型ビジュアルUI（写真付き一覧・検索）       │
│   ├── ドラッグ＆ドロップによる「融合（Merge）」「分離」 │
│   ├── 原本非破壊の手書きメモ育成（人間レイヤー）       │
│   └── 日常の投稿ノートと知識の双方向リアルタイム連動   │
└────────────────────────────────────────────────────────┘
```

## 🚀 1. Instagram完全移行パイプライン

単なるテキスト抽出ではなく、ObsidianおよびAI（LLM）が文脈を最も正確に理解できる構造化Markdownへ自動変換します。

* **4層YAMLフロントマター**: 識別（Entity）・時間（Temporal）・関係（Relation）・位置（Location）・原本（Raw）を分離した高精度メタデータを自動付与。
* **メディアの完全ローカル保持**: 7,000件超の画像（JPG）および動画（MP4）をローカル保存し、ノート内に `![[メディア名]]` 形式で埋め込み。
* **非破壊・原本保証**: 各ノートから原本JSON（RawData）へWikiリンクで接続し、データ欠損や情報ロストを完全に防止。
* **意味ネットワーク（Synapse）の自動生成**: ハッシュタグ・メンション（`@`）・位置情報を個別のSynapseノートとして独立生成し、相互リンクを自動構築。

---

## 🧠 2. Memory Synapse DB（Obsidianプラグイン）

移行した膨大な記憶（タグ・場所・人物）を、Obsidian上で視覚的に俯瞰し、人間が育てていくための専用プラグインです。

* **カード型ビジュアルUI**: 何千件ものSynapseを写真付きカードとしてグリッド表示。
* **記憶の「融合（Merge）」と「分離（Split）」**: 表記揺れ（例：「#大阪城」「Osaka Castle」）や同一人物の複数アカウントを、ドラッグ＆ドロップで直感的にひとつの知識グループへ統合。
* **原本非破壊の手書きレイヤー**: 元のInstagramログは一切書き換えず、人間の記憶や追加メモだけを別レイヤーとして安全に追記・育成。
* **投稿ノートとのリアルタイム連動**: 投稿ノートを開くと、含まれるタグや場所のカードが右サイドバーに自動表示。

## 🛡️ 3つの絶対安全設計（設計思想）

1. **非破壊原則（原本絶対保持）**
   * 原本JSONおよび抽出された生データは絶対に上書き・汚染しません。人間の追記や解釈は独立したレイヤーに保存されます。
2. **人間が意味を確定する（AI・機械の勝手な上書き禁止）**
   * 表記揺れや同一性の判断をAI任せにせず、AIは候補の提示にとどめ、最終的な統合判断は人間が行います。
3. **完全ローカル・プライバシー保護**
   * すべてのデータ変換およびプラグイン動作はローカル環境（Mac / Obsidian）内で完結し、外部クラウドへ個人情報が送信されることはありません。

## 💡 開発の背景と想い（About & Philosophy）

### 「毎回AIに自分を説明するのをやめたい」から始まった挑戦

本プロジェクトのオーナーは、プログラミング経験のないTAXI運転士です。
AIの学習を始める中で、短期間に数多くのツールを作成しましたが、そのたびに直面したのが**「AIに毎回自分の前提や文脈を一から説明しなければならない煩わしさ」**でした。

「自分の過去10年分の記録がすべて整理され、自分自身とAIが共通して理解できる知識基盤になっていれば、AIは真のパートナーになるはずだ」

この一つのアイデアから、約10年分のInstagramログを救出し、Obsidianというオープンで永続的なMarkdown環境へ移管する開発が始まりました。
プログラミング言語を一切読めない状態から、AIとの対話・検証・設計レビューを何百回と繰り返した結果、エンタープライズ水準の非破壊設計と、記憶を育てる専用Obsidianプラグイン「Memory Synapse」が誕生しました。

本リポジトリは、**「人生の記憶をAI時代の知識基盤へと進化させる」**ための実践記録であり、完成されたオープン基盤です。
